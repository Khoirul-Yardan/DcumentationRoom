# Sumber aset M1

Tambahan 14 Oktober: halaman dokumen `sample-mvp-page-*.png`, kartu video `sample-mvp-video-card.png`, dan video `sample-mvp-demo.mp4` merupakan fixture sintetis yang dibuat oleh `Tools/prepare_mvp.py` menggunakan bentuk, teks, dan nada sinus lokal. Tidak mengandung karya atau identitas pihak ketiga. Teks dirasterisasi menggunakan Arial yang terpasang di Windows; berkas font tidak disalin/didistribusikan. Encoding melalui ffmpeg lokal (H.264/AAC); ffmpeg tidak dibundel dalam game. Cover world-space memakai media fixture existing, tanpa asset store tambahan.

Kit model `.obj` existing mencakup 24 jenis di `Assets/_Project/Art/Models`, sumber generator `Tools/create_museum_models.py`; tidak diganti pada sesi MVP. Lisensi Unity/TMP dan asset rendering template tetap berlaku.

| Aset | Sumber | Catatan |
|---|---|---|
| Geometri museum, stan, tanaman, bangku | Primitive Unity disusun oleh AtlasBuilder untuk proyek ini | Tidak ada model/asset store berbayar atau logo pihak ketiga |
| Palet | Spesifikasi PROJECT ATLAS | Material URP dibuat lokal |
| 3 diagram PNG contoh | `Tools/prepare_atlas.py`, dibuat untuk proyek ini | Data sintetis, bukan bukti karya nyata |
| Liberation Sans SDF, TMP shader/material | TMP Essential Resources dari package uGUI terpasang | Lisensi font/package bawaan dipertahankan bersama import; periksa notices untuk distribusi |
| Rendering template | Proyek Unity Universal 3D pengguna | Asset asli tidak dihapus |

Tidak ada konten Google Drive yang diunduh/disalin/dipublikasikan. Audit hak akses konten nyata dilakukan pada milestone integrasi.
