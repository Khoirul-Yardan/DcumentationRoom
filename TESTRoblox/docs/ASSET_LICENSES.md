## Kandidat Creator Store — belum terpasang

[Forest Pack, @Roblox, ID 6432306802](https://create.roblox.com/store/asset/6432306802) menampilkan **Get Model** dan deskripsi pohon, tanaman, batu serta fauna. Halaman juga mencatat 13 script. Paket ini hanya dicatat sebagai kandidat; unduhan tidak berhasil dilakukan dalam sesi ini. Tidak ada `InsertService:LoadAsset` runtime, dynamic require, atau dependensi ID paket di place.

Jika diimpor nanti, ambil melalui Toolbox Studio, periksa semua descendant, pilih beberapa props, buang script/efek tidak diperlukan, dan uji material serta izin mesh di experience. Detail penggunaan Toolbox tersedia pada [dokumentasi Roblox](https://create.roblox.com/docs/projects/assets/toolbox).
